# 🌤️ 날씨 대시보드 (Weather Dashboard)

실시간 날씨 정보를 제공하는 웹 기반 날씨 대시보드입니다. OpenWeatherMap API를 사용하여 현재 날씨와 5일 예보를 제공합니다.

## 🌟 주요 기능

### 1. 실시간 날씨 정보
- 도시명 검색으로 현재 날씨 조회
- 현위치 기반 날씨 정보 자동 감지
- 상세한 날씨 데이터 표시

### 2. 날씨 정보
- 현재 온도 및 날씨 상태
- 체감 온도
- 습도, 기압, 풍속
- 구름양, 가시거리
- 일출/일몰 시간
- 강수량, 온도 범위

### 3. 5일 예보
- 앞으로 5일간의 날씨 예보
- 날짜별 예상 온도
- 날씨 상태 아이콘

### 4. 즐겨찾기
- 자주 확인하는 도시 즐겨찾기 추가
- 클릭 시 해당 도시 날씨 조회
- 각 도시의 현재 온도 표시
- LocalStorage에 저장되어 영구 보존

## 🚀 시작하기

### 1. API 키 획득
1. [OpenWeatherMap](https://openweathermap.org/api)에 접속
2. 무료 계정 생성
3. "Current Weather Data" API 키 생성

### 2. API 키 설정
`script.js` 파일에서:
```javascript
const API_KEY = 'YOUR_API_KEY_HERE'; // 여기에 API 키를 입력
```

### 3. 브라우저에서 실행
`index.html` 파일을 브라우저에서 열면 됩니다.

## 📋 사용 방법

### 도시 검색
1. 검색창에 도시명 입력 (예: 서울, Seoul)
2. 검색 버튼 클릭 또는 엔터키 입력
3. 해당 도시의 날씨 정보 표시

### 현위치 기반 날씨
1. "📍 현재 위치" 버튼 클릭
2. 위치 접근 권한 승인
3. 현재 위치의 날씨 자동 표시

### 즐겨찾기 추가
1. "⭐ 즐겨찾기 도시" 섹션의 "+ 즐겨찾기 추가" 버튼 클릭
2. 도시명 입력
3. 추가 버튼 클릭
4. 즐겨찾기에서 클릭하면 해당 도시 날씨 조회

### 즐겨찾기 제거
1. 즐겨찾기 도시 카드의 "✕" 버튼 클릭
2. 즐겨찾기에서 제거됨

## 🛠️ 기술 스택

- **HTML5**: 구조
- **CSS3**: 스타일링 및 반응형 디자인
- **JavaScript**: 기능 구현
- **OpenWeatherMap API**: 날씨 데이터

## 📱 반응형 디자인

- 데스크톱 (1000px 이상)
- 태블릿 (768px ~ 999px)
- 모바일 (768px 이하)

## 🎨 UI 특징

- 아름다운 그래디언트 배경
- 직관적인 사용자 인터페이스
- 실시간 로딩 표시
- 에러 메시지 표시
- 날씨별 이모지 아이콘
- 부드러운 애니메이션

## 💾 데이터 저장

- 즐겨찾기 도시는 브라우저의 LocalStorage에 저장
- 브라우저를 닫아도 데이터 유지
- 데이터 초기화는 브라우저 저장소 삭제 필요

## ⚠️ 주의사항

- OpenWeatherMap 무료 API는 1분에 60회 호출 제한
- API 키는 개인 키이므로 공개하지 않기
- 도시명은 영문 또는 한글로 입력 가능
